# 네이티브 v6.7 검증

- C++ 네이티브 Windows x86 EXE 크로스 컴파일 성공. 별도 런타임 설치 없음.
- 기존 CSV/조회 코어 28 assertions, 위치 기반 가져오기/분류 관리 27 assertions 통과.
- 검사 내용: 임의 제목의 2칼럼/3칼럼 CSV, 첫 행을 제목으로 고정 제외, 상세정보 생략, 분류명 입력/중복 거부, 중복 조회키와 잘못된 칼럼 수/빈 파일 시 현재 DB 불변, 분류 일괄 이름 변경/삭제, 저장된 바이트와 편집 데이터 분리.
- 내장 manifest 6.7.0.0, asInvoker/uiAccess=false, SxS 의존성 없음, CLR 헤더 없음, Windows 기본 DLL만 Import 검사 통과.
- 변경은 저장 전 편집 목록만 갱신하며 조회는 저장 파일을 읽습니다. Windows 자체 점검에서만 합성 메모리 DB를 조회합니다.
- GUI/은행 PC/Windows 자동 입력의 실제 실행은 이 Linux 환경에서 검증하지 않았습니다. 자체 점검과 대상 PC에서 수동 확인이 필요합니다.

## v6.7 DB 셀 선택

DB 목록의 클릭 위치를 셀로 판별한 뒤 읽기 전용 Windows EDIT를 해당 위치에 표시하고 마우스 드래그를 전달합니다. Ctrl+C/Ctrl+A는 기존 네이티브 텍스트 컨트롤을 사용합니다. 상세정보는 여러 줄로 펼칩니다. 목록 변경·스크롤·탭 이동 시 닫습니다. Windows 자체 점검에 DB 셀 부분 복사 및 읽기 전용 검사도 포함했지만 이 환경에서 실행하지 않았습니다. 크로스 컴파일, 코어 및 CSV 테스트, 내장 매니페스트·의존성 검사를 수행했습니다.
