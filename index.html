02 / 아이디어의 출발

크롬의 선택 후 번역 경험에서
아이디어를 얻었습니다.

해석하기 어려운 외국어를 드래그하고 우클릭해 바로 번역을 확인하는 경험을 업무 정보 조회에 적용했습니다.

크롬의 번역 경험

  1. 이해하기 어려운 외국어 선택
  2. 드래그 + 우클릭
  3. 번역 결과를 바로 확인

업무 정보 조회에 적용

  1. 의미를 확인할 코드 선택
  2. 드래그 + 단축키 입력
  3. 등록된 정보를 바로 확인

03 / 조회 방법

드래그하고 단축키를 누르면
결과 카드가 열립니다.

사용자가 Ctrl+C를 먼저 누를 필요가 없습니다. 기본 단축키는 F8이며 설정에서 변경할 수 있습니다.

업무 화면 / 요청 인터페이스 ID기능 설명용 예시

이 웹 화면은 설명용 예시입니다. 실제 전역 단축키 조회는 Windows 프로그램에서 동작합니다. 결과 텍스트를 선택해 Ctrl+C로 복사하고, Esc 또는 바깥 클릭으로 닫을 수 있습니다.

웹 · 메모장 · 한글 · Word · PPT의 복사 가능한 텍스트 영역에서 사용합니다.

06 / 구조와 실행 환경

한 개의 네이티브 EXE와
로컬 CSV로 구성합니다.

C++ / Windows API 기반으로, 프로그램 실행 중 인터넷에 접속하지 않습니다.

추가 런타임 설치 없음

  • .NET, Java, Python 불필요
  • 별도 C++ 재배포 패키지 불필요
  • Excel·DB 서버·확장 설치 불필요
  • Windows 기본 DLL 사용

실행 환경

  • Windows 7 이상을 대상으로 제작
  • x86·x64 Windows용 32비트 EXE
  • 일반 사용자 권한으로 실행
  • EXE 실행을 허용하는 PC 정책

파일 접근 권한

  • 조회: CSV 읽기 권한
  • 설정: 사용자 폴더 쓰기 권한
  • DB 저장: 해당 폴더 쓰기·교체 권한
  • 임시 파일·잠금 파일·백업 생성
WorkLookup.exe+CSV 데이터+사용자 설정
07 / 입력 처리와 보안

Windows 기본 기능으로
단축키와 복사를 처리합니다.

추가 후크·드라이버 없이 구성하되, 조직의 PC 정책을 따릅니다.

동작 방식

  1. RegisterHotKey로 단축키 등록
  2. 눌렀을 때 SendInput으로 Ctrl+C 요청
  3. 클립보드의 텍스트로 조회
  4. 지원 가능한 기존 클립보드 내용은 복원

동작 조건과 한계

  • 복사 가능한 텍스트만 조회 가능
  • 높은 권한의 앱에는 입력이 제한될 수 있음
